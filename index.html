Arknights Gacha Simulator

Engine
Unity
Platform
Android

A fan-made gacha simulator based on Arknights, built as a learning project. It recreates the game's summoning screens so I could study how its UI flow and randomization work.

Features

  • Animated L2D Characters – Some characters play their Live2D animations.
  • Gacha Collection Display – Shows every character you've pulled.
  • Layered UI with Scroll Effects – The gacha pool screen has UI layers that scroll at different speeds for a parallax effect.
  • Selectable Rate-Up Characters – Pick and switch the rate-up character on each banner.
  • Pity System – A 5★ is guaranteed within the first 10 pulls, and 6★ pity is shared across all banners.
  • Resolution Sidebar – Settings to adjust the UI for different phone screen sizes.
