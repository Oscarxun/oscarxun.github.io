Arknights Gacha Simulator

Engine Unity  ·  Platform Android

A fan-made gacha simulator project developed for learning purposes, inspired by Arknights. The simulator replicates the game's summoning experience and interface to study UI flow and randomization systems.

Features

  • Animated L2D Characters – Display live 2D animations for certain characters.
  • Gacha Collection Display – Show all characters obtained from gacha pulls.
  • Layered UI with Scroll Effects – Different UI layers scroll at varying speeds in the gacha pool interface.
  • Selectable Rate-Up Characters – Ability to choose and switch the rate-up character on each banner.
  • Pity System Implementation – Guaranteed 5★ character on the first 10 pulls; shared 6★ pity across all banners.
  • UI Sidebar for Mobile Resolution Adjustments – Settings to modify UI for different mobile screen resolutions.
